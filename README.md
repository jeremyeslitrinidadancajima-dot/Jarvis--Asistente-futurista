# Jarvis--Asistente-futurista
Inspirado en Iron Man, con inteligencia artificial, voz masculina en español, reactor Arc azul animado, interfaz holográfica futurista, comandos de voz, animaciones 3D, paneles tecnológicos y diseño adaptable a teléfonos Android y computadoras portátiles. Proyecto gratuito, con opción de instalación como PWA y conexión HTTPS
